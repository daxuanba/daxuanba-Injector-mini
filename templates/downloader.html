下载管理

一、网络连接（直连到底通不通）

点「测直连」真实打一遍 Steam 商店 / 社区 / API / 图片 CDN 与 GitHub。 全部通 = 不需要加速；只有社区不通 = 典型国内环境，开加速即可。
直连不通 / 社区打不开时，把你本机代理（VPN、mihomo 之类）填进上面，保存后 重启应用生效。后端所有 Steam / GitHub 请求都会走它，比只加速浏览器彻底。

二、内核（三个可以同时装到 Steam 主目录）

下载全程走本程序自己的网络通道，不会打开任何浏览器；三个内核都由程序 自动从上游拉取，不需要你手动丢任何文件。安装方式按内核类型走：
· OpenSteamTool / GreenLuma：下载完直接把文件释放到 Steam 对应目录， 全程无窗口；
· SteamTools：官方只发安装包（st-setup-x.y.z.exe）， 程序下完直接运行安装包本身 —— 管理员身份下加 /S 静默安装、不显示任何窗口；普通权限则弹出官方安装向导。
版本号是对着下载源真实比对的：已经是最新就显示「已是最新」，不会让你反复更新。

三、启动 Steam / 注入检测

GreenLuma 有两种形态：隐身版（推荐）把改写过的 user32.dll 放进 Steam 主目录， Steam 启动时自己加载 —— 不用注入器、不用管理员、没有任何窗口，也不怕 Steam 更新； 注入版用 DLLInjector.exe 往 steam.exe 里挂钩子，全程同样无窗口，但对 Steam 版本敏感。 有没有真正生效，用「检测注入」真查进程模块，不靠猜。
